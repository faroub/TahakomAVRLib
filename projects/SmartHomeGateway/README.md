# Smart Home Gateway Project

An integrated smart home peripheral node that provides:
* Servo door lock actuation
* Pushbutton door toggle control
* Buzzer audio confirmation tones
* LDR ambient light sensing
* OLED 128x64 display status rendering
* Real-time hardware telemetry over USART0

## Hardware Pinout
* OLED I2C: PC4 (SDA), PC5 (SCL)
* Servo Lock: PB1
* Door Pushbutton: PD2
* Buzzer: PD3
* LDR Sensor: PC0
